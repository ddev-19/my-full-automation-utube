# Privacy Policy — Pauranik Kathaye uploader

This is a private tool used only by the owner of the YouTube channel
"पौराणिक कथाएँ / Pauranik Kathaye" (https://www.youtube.com/@PauranikKathayeBharat)
to upload the channel's own videos, thumbnails and captions.

- It uses Google sign-in only to access the owner's own YouTube channel through the YouTube Data API.
- It does not collect, store, sell or share any data about other people.
- OAuth tokens are kept as encrypted GitHub Actions secrets and used only to upload videos to this channel.
- Access can be revoked at any time at https://myaccount.google.com/permissions.

Contact: via the YouTube channel's About page.
